# Neon Odyssey — Sub-Class Icon Art Prompts

Matched to the existing 13 class icons: a **flat vector class-crest emblem** — one bold centered symbol on a near-black background, filled top-to-bottom with a smooth gradient from **bright lemon-yellow → gold → amber → magenta-pink**, thick clean rounded linework with dark negative-space detail cut into the shape, balanced and roughly symmetrical, square 1:1, no text, no scene, no outer glow, reads clearly at small size.

Each prompt below is one complete, ready-to-paste paragraph. The style clause is baked into every one — nothing to combine. Each sub-class **echoes its parent class's motif** (noted per section) so the set reads as a family, then twists toward the sub-class theme.

**Suggested negative prompt (same for all):** photo, portrait, realistic face, 3D render, background scene, text, letters, watermark, busy, cluttered, multiple colors, blue, green, low contrast.
