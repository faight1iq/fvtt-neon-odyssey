# Neon Odyssey — Class Icon Art Prompts

Each class is one complete, ready-to-paste paragraph, sized as a **128×128 pixel class icon**: square 1:1, tight head-and-shoulders bust, bold clean silhouette that stays readable small, simple background, stylized semi-realistic sci-fi.

**Approach:** every class is a D&D archetype in sci-fi clothing, so each prompt leads with the archetype ("high-tech warlock," "high-tech knight") and loads its iconic signifiers, then skins them in tech. The archetype each class maps to is noted in its heading — sanity-check these against the book; if I mapped one wrong, the whole prompt needs to change.

**Suggested negative prompt (same for all):** busy background, cluttered, tiny fine details, full body, extra limbs, deformed hands, text, watermark, logo, low contrast, blurry.
